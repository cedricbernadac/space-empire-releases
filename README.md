# Space Empire

Installateurs du jeu Space Empire. Télécharge le dernier `Space-Empire-…-win-x64.exe` dans [Releases](../../releases/latest), lance-le, et le jeu se mettra ensuite à jour tout seul.

Windows peut afficher « éditeur inconnu » à la première installation : « Informations complémentaires », puis « Exécuter quand même ».
